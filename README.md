# 🗄️ Relational Database Architecture & SQL Business Analytics

A production-grade SQL script demonstrating relational data modeling, 3NF schema design, and advanced analytical queries using Common Table Expressions (CTEs) and Window Functions for business KPIs.

## 📌 Capabilities Demonstrated
- **Schema Normalization:** Normalized 3NF architecture linking Customers, Orders, and Order Items with strict referential integrity.
- **Analytical Metrics:** Month-over-Month (MoM) revenue growth using `LAG()`, and customer RFM segmentation using `DENSE_RANK()`.
- **Query Optimization:** Efficient multi-table joins and aggregation pipelines designed for decision support.

## 🛠️ Tech Stack
- SQL (PostgreSQL / MySQL / Microsoft Access)
- Relational Schema Design (3NF)
